# nobinoby-tracker
최근 실시된 기말고사 직후, 평소 성적이 하위권이던 학생 노진구가 한문 시험에서 만점에 가까운 성적을 받아 평소 노진구를 무시하던 비실이 측에서 의혹이 제기되었다. 특히 진구가 평소 헷갈려 하던 함정 문제까지 정확히 맞힌 점이 석연치 않아 엄마에게 일렀고, 분노한 비실이의 엄마는 학교에 정식 조사를 의뢰했다. 학교 측은 진구가 사용하는 PC를 조사하기로 했다.
